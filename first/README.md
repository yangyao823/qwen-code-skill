# Qwen Code 可视化工作流编排 Skill

为 [Qwen Code](https://github.com/QwenLM/Qwen-Code) 终端 AI Agent 提供可视化工作流编排能力。通过拖拽节点、连线、一键执行，让复杂的多步骤 AI 编程任务变得直观可控。

> 本项目全程使用 Claude Code 通过自然语言描述生成，零手动编码。

## 功能特性

- **6 种任务节点**：文件操作、Shell 执行、AI 分析、HTTP 请求、条件判断、延时等待
- **拖拽编排**：从左侧面板拖拽节点到画布，从节点边缘拖出连线
- **属性编辑**：点击节点即可在右侧面板编辑参数（命令、路径、提示词等）
- **批量执行**：按拓扑序依次执行所有节点，实时显示进度和状态
- **执行日志**：右侧面板查看每个节点的运行结果和时间戳
- **右键菜单**：支持复制、删除节点
- **导出功能**：将工作流导出为 JSON 文件，便于分享和复用
- **循环检测**：自动检测节点间的循环依赖并阻止执行
- **暗色主题**：黄绿色系现代 UI，长时间使用不疲劳

## 快速开始

### 安装

无需安装任何依赖，单个 HTML 文件即可运行：

```bash
# 克隆仓库
git clone https://github.com/your-username/qwen-code-workflow-skill.git
cd qwen-code-workflow-skill

# 直接用浏览器打开
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

或者使用任意 HTTP 服务器：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

然后访问 `http://localhost:8080`。

### 系统要求

- 现代浏览器（Chrome 90+、Firefox 88+、Safari 14+、Edge 90+）
- 无需 Node.js、无需 npm、无需构建工具

## 使用方法

### 1. 添加节点

从左侧面板拖拽节点类型到画布区域：

| 节点 | 说明 | 可配置参数 |
|------|------|-----------|
| 📄 文件操作 | 读写文件内容 | 操作类型、文件路径、内容 |
| 💻 Shell 执行 | 运行命令行指令 | 命令、超时时间 |
| 🤖 AI 分析 | 智能代码分析 | 模型选择、提示词 |
| 🌐 HTTP 请求 | 调用外部 API | 方法、URL、请求体 |
| 🔀 条件判断 | 分支逻辑控制 | 条件表达式、分支标签 |
| ⏱️ 延时等待 | 暂停指定时间 | 等待时间、单位 |

### 2. 连接节点

从节点边缘拖拽到另一个节点，创建有向连线，表示执行顺序。

### 3. 编辑属性

点击任意节点，右侧面板显示其可编辑属性。

### 4. 执行工作流

点击右上角「执行工作流」按钮，系统按拓扑序依次执行所有节点：
- 执行过程中可随时点击「停止执行」中止
- 执行进度实时显示
- 每个节点的状态会更新（等待中 → 运行中 → 成功/失败）

### 5. 导出工作流

点击「导出」按钮，将当前工作流保存为 JSON 文件。

## 技术栈

- **前端**：纯 HTML5 + CSS3 + ES6+ JavaScript
- **图表库**：[vis-network](https://github.com/visjs/vis-network) 9.1.6（CDN 引入）
- **字体**：Inter（Google Fonts CDN）
- **无构建工具**，无打包依赖，无后端服务

## 接入 Qwen Code

本 Skill 设计为 Qwen Code 的可视化前端扩展。通过 `.mcp.json` 配置文件，可以将工作流执行能力接入 Qwen Code 的 MCP（Model Context Protocol）生态。

详见 [`.mcp.json`](./.mcp.json) 配置说明。
